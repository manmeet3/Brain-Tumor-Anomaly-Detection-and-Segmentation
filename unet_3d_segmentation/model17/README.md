# Pre-trained Models (BraTS 2017)

Checkpoint files trained on the BraTS 2017 configuration (`config17/`) live in this folder, one set per tumor sub-region (whole tumor `wt`, tumor core `tc`, enhancing core `en`) and view (axial, sagittal, coronal).

If checkpoints are missing, download them from [Google Drive](https://drive.google.com/open?id=1moxSHiX1oaUW66h-Sd1iwaTuxfI-YlBA) and place the files directly in this folder. See the [top-level README](../README.md) for how these are used during testing.
